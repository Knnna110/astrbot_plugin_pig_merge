# 合成大猪猪 · 网页版 v3

浏览器里玩的「合成大西瓜」式物理合成游戏，主题换成猪。游戏页单独占一个端口，
管理台直接挂在 AstrBot 面板里，不额外开端口。

## 功能

- **游戏页**：真物理的 9 级合成（🐽 → 🐷 → 🐖 → 🐗 → 🥓 → 🍖 → 🍔 → 🍲 → 👑），
  鼠标/触屏/键盘都能玩，深浅色跟随系统也能手动切，分数自动上榜。
- **排行榜**：总榜 + 本群榜（从群里点链接进来才看得到本群榜）。
- **聊天入口**：群里 **@机器人** 并带上「🐖游戏」（🐖/🐷/猪 和 游戏必须连在一起）
  就会发专属入口链接。没注册会先让你登记名字。
- **注册绑定**：`猪猪注册 名字` 建一个猪农档案，把当前会话的 UMO 和你的账号绑上；
  之后拿到的链接自带凭证，打开就是你的档案，分数直接记在名下。
- **面板管理台**：查看猪农档案、对局记录、今日局数、最高分；清分、删档；
  改端口、对外地址、榜单人数、Markdown 模式等。
- **消息降级**：QQ 官方机器人用 Markdown，其他平台自动降级为纯文本。

## 安装

把整个目录放进 `data/plugins/`，然后在面板里重载插件。

- 游戏页默认监听 `0.0.0.0:6100`，端口范围 **6100~6110**。
  配置端口被占用时，会在范围内自动往后顺延；全被占才会启动失败。
- 群里发的链接默认用本机内网 IP。服务器有公网 IP / 反代时，
  在「猪猪管理台 → 运行设置 → 对外地址」填 `http://你的IP:6100`。
- 公网访问需要在防火墙 / 安全组放行对应端口（端口以管理台显示的实际端口为准）。

## 聊天用法

| 发送 | 结果 |
| --- | --- |
| `@机器人 🐖游戏` | 已注册：发专属链接 + 个人最高分 + 总榜前三；未注册：提示先登记名字 |
| `@机器人 🐷游戏` / `猪猪游戏` / `合成大猪猪` | 同上 |
| `猪猪注册 小猪快跑` | 注册猪农档案，绑定当前会话；重名会提示换一个 |
| `猪猪认领 8K3M5Q` | 换设备 / 换平台时把旧档案迁过来 |

> 这三个指令是用 AstrBot 正规 `@filter.command` 注册的，
> 装了 `astrbot_plugin_help` 的话，发「帮助」生成的帮助图里能看到它们。

> 群里必须真的 @ 到机器人；只发「🐖游戏」不会触发。
> 私聊里没有 @ 这回事，可以直接发「🐖游戏」（可在管理台关掉私聊入口）。

## 管理台

面板 → 插件 → 合成大猪猪 → **猪猪管理台**（`views/admin`）。

- 服务状态、实际端口、对外地址、数据库路径
- 猪农统计 / 今日对局 / 最高分
- 猪农档案：搜索、清分、删档
- 最近 30 条对局
- 运行设置：端口（6100~6110）、对外地址、监听地址、榜单人数、交分间隔、
  Markdown 模式、允许私聊、链接带会话标记

改端口或监听地址会立刻重启游戏页，不用重载整个插件。

## 数据

- 数据库：`data/plugin_data/astrbot_plugin_pig_merge/scores.db`（SQLite，WAL）
- 玩家档案里保存：注册名、最高分、局数、绑定的 UMO / UID / 聊天昵称 / 群名、入口 token
- 单局记录默认保留 365 天，个人最高分永久保留；每人最多留最近 80 局

## v3.1.0 更新

### 猪猪球换成真贴图
- 九级都有图：小猪崽 / 苹果猪 / 大懒猪 / 野猪 / 培根 / 烤猪串 / 猪排堡 / 锁冠猪王 / 猪神。
- 图跟着球的半径缩放，圆形裁切，加了内阴影和高光，看着是个球不是贴纸。
- 预渲染成 sprite 缓存，一百多个球也不会每帧重算裁切；贴图没加载完或加载失败会自动退回 emoji，不会白屏。
- 素材在 `web/pigs/`，想换自己的图直接替换同名 PNG（240×240 最好）。

### 渲染修的几个坑
- `aspect-ratio` 在部分 QQ/UC 内核里不生效，罐子高度会变 0、画布一片空白 —— 现在用 JS 兜底撑高度。
- 画布清屏改成按设备像素清，窗口缩放后不再留残影；缩放比例取宽高较小值，不再把画面拉变形。
- 高 DPI 下贴图按实际像素渲染，手机上不糊。

### 绑定这块说清楚
`UMO` 是 AstrBot 的会话键，格式 `平台:消息类型:会话ID`。QQ 官方机器人给的是 **openid**（一串哈希），不是 QQ 号；只有 OneBot/ NapCat 这类才会是数字群号。所以「看着乱」是平台特性，不是绑定错了。

真正决定绑到谁的，是消息事件里的 `sender_id` + `umo`：

- 同一个人在同一机器人下的 openid 是稳定的，档案不会天天串。
- 换平台（官方 ↔ OneBot）会变成另一个 openid，这时候用**迁移码**把旧档案迁过来：网页「我的」里点「换设备 / 换平台」拿 6 位码，新会话里发 `猪猪认领 8K3M5Q`。
- 管理页现在会显示 `平台 · 群聊/私聊 · 会话尾号`，鼠标悬停能看完整 umo 和发送者 ID，方便核对是不是同一个人。

### 链接改成一次性门票
以前群里发的链接里带的是长期凭证，谁点谁就是这个号。现在链接里只放一次性门票（默认 600 秒、只能用一次），点开后才把长期凭证存进浏览器本地，票据从地址栏抹掉。捡到别人的旧链接基本是废的。
