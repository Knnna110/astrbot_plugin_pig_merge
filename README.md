## 简介

把「合成大西瓜」的玩法做成了**聊天入口 + 独立网页**：

- **玩起来不用装东西**：链接在手机、平板、电脑浏览器里都能开，支持触屏、鼠标和键盘。
- **成绩存在自己机器上**：分数、局数、个人最高分都在插件自己的 SQLite 里，换浏览器也能找回来（设过口令即可登录）。
- **管理台就在 AstrBot 面板里**：看服务状态、查玩家、看对局、改运行参数，不用另外的界面。
- **不内置任何地址**：游戏页监听哪个地址、发出什么样的链接，全部由插件配置决定。

游戏页是插件自己拉起的一个轻量 HTTP 服务，默认 `6100`，被占用时在 `6100~6110` 内顺延，与 AstrBot 面板互不影响。

## 功能

| 能力 | 说明 |
|---|---|
| 九级合成 | 🐽小猪崽 → 🐷苹果猪 → 🐖大懒猪 → 🐗野猪 → 🥓培根 → 🍢烤猪串 → 🍔猪排堡 → 👑锁冠猪王 → ✨猪神 |
| 物理手感 | 内置圆体碰撞引擎（重力 / 摩擦 / 迭代求解），堆过危险线太久判负 |
| 出球规则 | 只出前三级，比例随分数变化；同一等级最多连出 3 次 |
| 音效 | 合成、落地、升天、终局都有声音，WebAudio 现场合成，不带音频文件，可一键静音 |
| 自定义背景 | 配置里填一张图（直链或站内路径），页面垫一层柔光遮罩 |
| 排行榜 | 总榜 + 会话榜；聊天里发 `猪猪排行榜` 直接看，模型也能自己调工具查 |
| 个人档案 | 昵称、最高分、局数、最近对局，注册后与当前会话绑定 |
| 换设备 | 六位迁移码 `猪猪认领 8K3M5Q`，把旧档案迁到新会话 |
| 一次性入口 | 聊天里发的链接只带一次性门票（默认 600 秒、点一次失效），长期凭证只存在浏览器本地 |
| 彩蛋 | ✨猪神 是顶级，两颗撞一起会一起升天，直接加 5000 分 |
| 深浅色 | 跟随系统或手动切换，选择记在本地 |
| 消息降级 | QQ 官方机器人走原生 Markdown，其他平台自动降级纯文本 |
| 面板管理台 | 服务状态、实际端口、玩家查询、清分删档、对局记录、运行设置 |

## 安装

要求 AstrBot `>= 4.16`。

```bash
cd /root/AstrBot/data/plugins
git clone https://github.com/Knnna110/astrbot_plugin_pig_merge.git astrbot_plugin_pig_merge
```

然后在 AstrBot 面板里重载插件（或重启 AstrBot）。

- 依赖只有 `aiohttp`，AstrBot 自带，一般不用另外安装。
- 安装目录以你的实际部署为准，上面是默认路径。

## 网络与对外访问

- 游戏页默认监听 `0.0.0.0:6100`，端口被占用会在 `6100~6110` 内顺延，实际端口以管理台显示为准。
- **插件不包含任何预设地址**：发出去的链接由配置项 `public_base_url` 决定，留空时会退回本机地址。
- **要让人从外部访问，需要自行处理对外地址和端口**：端口映射、反向代理、域名、HTTPS、防火墙 / 安全组放行，都在插件之外完成；插件不做内网穿透，也不会自动探测外部地址。
- 外部可访问之后，在插件配置（或管理台「运行设置」）里把 `public_base_url` 填成外部能打开的地址即可。

## 聊天用法

> 触发规则是「**@ 到机器人** + 关键词」，不做普通聊天关键词匹配，避免刷屏。
> 私聊里没有 @ 这回事，可以直接发（可在配置里关掉私聊入口）。

| 发送 | 结果 |
|---|---|
| `@机器人 🐖游戏` | 已注册：回入口链接 + 个人最高分 + 总榜前三；未注册：提示先登记名字 |
| `@机器人 🐷游戏` / `猪猪游戏` / `合成大猪猪` | 同上 |
| `猪猪注册 小猪快跑` | 注册档案并绑定当前会话，重名会提示换一个 |
| `猪猪认领 8K3M5Q` | 换设备 / 换平台时，把旧档案迁到当前会话 |
| `@机器人 猪猪排行榜` | 榜单：当前会话有成绩先给会话榜，否则给总榜，末尾附自己的名次 |

> 入口指令用 AstrBot 的 `@filter.command` 注册；装了 `astrbot_plugin_help` 的话，发「帮助」生成的帮助图里能看到它们。

排行榜另外挂了一个函数工具 `pig_merge_leaderboard`：有人随口问「谁分最高」「我排第几」，
模型会自己调它把榜单发出来，不用背指令。参数两个 —— `scope`（`all` 总榜 / `session` 当前会话 / `auto` 默认优先会话）
和 `limit`（1~20，填 0 用配置里的 `board_size`）。

## 配置项

在面板 → 插件 → 合成大猪猪 → 配置里改，或编辑
`data/config/astrbot_plugin_pig_merge_config.json`。

| 配置 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `host` | string | `0.0.0.0` | 游戏页监听地址 |
| `port` | int | `6100` | 游戏页端口，6100~6110，占用自动顺延 |
| `public_base_url` | string | 空 | 对外访问地址，如 `https://pig.example.com`；留空用本机地址 |
| `bg_image` | string | 空 | 自定义背景图，`http(s)://` 直链或站内路径；留空用默认渐变 |
| `markdown_mode` | string | `auto` | `auto` 仅 QQ 官方用 Markdown；`always` / `never` 强制 |
| `board_size` | int | `10` | 聊天里报榜时列几个人（3~20） |
| `session_link` | bool | `true` | 链接带会话标记，网页里可以看会话榜 |
| `allow_private` | bool | `true` | 允许私聊要链接 |
| `submit_interval` | float | `1.5` | 同一玩家交分最小间隔（秒），防连点刷榜 |
| `keep_days` | int | `365` | 单局记录保留天数，个人最高分不受影响 |
| `default_theme` | string | `auto` | 网页默认主题：`auto` / `light` / `dark` |
| `link_ttl` | int | `600` | 入口链接有效期（秒），60~86400，点一次即作废 |

## 管理台

面板 → 插件 → 合成大猪猪 → **猪猪管理台**。

- 服务状态：是否在跑、实际端口、当前生效的对外地址、数据库路径
- 概览：猪农数、已绑定数、总对局、今日对局、最高分
- 玩家档案：按名字搜索、看绑定信息、清分、删档
- 对局记录：最近的对局流水
- 运行设置：端口、监听地址、对外地址、榜单人数、交分间隔、Markdown 模式、私聊开关、会话标记

改端口或监听地址会重启游戏页，不用重载整个插件。

## 数据与隐私

- 数据库：`data/plugin_data/astrbot_plugin_pig_merge/scores.db`（SQLite，WAL 模式）
- 档案里存：注册名、最高分、局数、绑定的会话与发送者标识、聊天昵称、口令哈希
- 口令用 PBKDF2-SHA256 加盐哈希保存，**不存明文**；入口 token 是随机串，等同登录凭证
- 单局记录默认保留 365 天，个人最高分永久保留；每人最多留最近 80 局
- 插件不向外部发起请求，数据都留在你自己的机器上

> 入口链接里的 token 就是登录凭证，别随手截图外传；过期了重新 @机器人 要一条就好。

## 常见问题

**点开链接打不开**

链接里的地址是你配置的 `public_base_url`。如果配置的是本机 / 内网地址，外部自然连不上——把对外地址和端口处理好，并把它填进配置。

**注册后换了浏览器进不去**

用新链接打开时会引导补设口令；实在不行在管理台删档重注册。

**提示「名字被占用了」**

同名档案已存在。要么登录进去，要么换个名字（`猪猪注册 别的名字`）。

**为什么会话标识是一串看不懂的哈希？**

QQ 官方机器人给的是 openid，不是 QQ 号，这是平台特性；同一个人在同一机器人下是稳定的。
换平台会变成另一个 openid，这时用迁移码把旧档案迁过来。

**两颗猪神撞一起没反应？**

3.4.0 起已修复，顶级同样参与合并判定。如果还是没反应，先强制刷新一次页面，确认拿到的是新的 `physics.js`。

**画布一片空白**

部分内置浏览器内核不支持 `aspect-ratio`，3.1.0 起有 JS 兜底；还白就换个浏览器（Chrome / Safari / 微信内置均可）。

**没有声音**

浏览器要求先有一次点击才能出声，先点一下画面再丢猪；右上角 🔊 可以随时开关。

## 目录结构

```
astrbot_plugin_pig_merge/
├─ main.py                  # 后端：存储、触发、游戏页 HTTP 服务、管理 API
├─ _conf_schema.json        # 插件配置
├─ metadata.yaml            # 插件元数据
├─ logo.png                 # 插件图标
├─ web/                     # 游戏页静态资源
│  ├─ index.html
│  ├─ style.css
│  ├─ game.js               # 玩法、渲染、音效、档案与登录
│  ├─ physics.js            # 圆体碰撞物理
│  └─ pigs/l1~l9.png        # 九级猪猪贴图
├─ views/admin/             # 面板内管理台
├─ .astrbot-plugin/i18n/    # 管理台中英文案
├─ CHANGELOG.md
└─ LICENSE
```

换猪猪的图：直接替换 `web/pigs/l1~l9.png`，建议 240×240 透明底 PNG。
想加等级：`web/physics.js` 里的 `LEVELS` 是纯数据表，追加一项、补一张 `l10.png` 即可。
